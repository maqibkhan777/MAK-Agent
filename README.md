# ⚡ MAK-Agent: Multi-Agent AI Business Agency

`MAK-Agent` is an autonomous, multi-agent AI business agency built with **CrewAI**, **ChatGroq (Llama 3.3 70B)**, and **Streamlit**. It coordinates specialized AI agents (Business Analyst, Data Analyst, Financial Assessor, and Chief of Operations) to conduct market research, web scraping, data benchmarking, financial risk auditing, and executive strategy synthesis.

---

## 🏢 Agency Roster

| Agent | Role | Capabilities / Tools |
| :--- | :--- | :--- |
| **MAK** | Chief of Operations | Workflow supervision, multi-agent orchestration & final executive report synthesis. |
| **Business Analyst** | Market & Strategy Analyst | Market trends, competitor research, web scraping (`SerperDevTool`, `ScrapeWebsiteTool`). |
| **Data Analyst** | Quantitative Analyst | Data parsing, metrics validation, local document analysis (`FileReadTool`). |
| **Financial Assessor** | Risk & Feasibility Auditor | Margins, ROI calculations, unit economics, cost structures & commercial risk assessment. |

---

## 🛠️ Tech Stack

- **Framework**: [CrewAI](https://github.com/crewAIInc/crewAI)
- **LLM Engine**: [Groq](https://groq.com) (`llama-3.3-70b-versatile`)
- **Tools**: Serper Web Search, Web Scraper, File Reader
- **UI**: Streamlit (Dark-mode Glassmorphism UI)
- **Python**: Python 3.12 (`uv` environment)

## 🚀 Quickstart Guide

### 1. Prerequisites & Environment Setup

Ensure you have Python 3.12 installed. Clone the repository and navigate to the root directory:

```bash
git clone https://github.com/maqibkhan777/MAK-Agent.git
cd MAK-Agent
```

### 2. Set Up Virtual Environment & Dependencies

Using `uv` or standard virtualenv:

```bash
uv venv --python 3.12 .venv
.\.venv\Scripts\python.exe -m uv pip install -r requirements.txt -p .venv
```

### 3. Environment Variables (.env)

Create a `.env` file in the root directory:

```env
GROQ_API_KEY=your_groq_api_key_here
SERPER_API_KEY=your_serper_api_key_here
```

### 4. Launch the Web Interface

Run the Streamlit graphical user interface:

```bash
.\.venv\Scripts\streamlit.exe run app.py
```

Open `http://localhost:8501` in your browser to deploy agency requests.

---

## 📄 Output Persistence

Reports generated by the agency are automatically saved to `output/agency_report.txt` and available for 1-click download in the Streamlit UI.
